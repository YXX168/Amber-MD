# Amber MD 🦐

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

> 极简玻璃态 Markdown 阅读器

一款专注于 **美学与体验** 的 Markdown 文档阅读器，采用 glassmorphism（玻璃态）设计风格，支持 5 种霓虹动画主题。

---

## ✨ 特色功能

- 🎨 **5种霓虹主题** — 午夜/极光/森林/海洋/樱花，每款都有独特的渐变动画背景
- 📱 **玻璃态UI** — 毛玻璃卡片、透明浮动按钮，现代感十足
- ☁️ **WebDAV云同步** — 连接坚果云/NextCloud等，随时随地访问文档
- 🌙 **沉浸式阅读** — 自动隐藏顶栏、返回顶部按钮、搜索高亮
- 📍 **继续阅读** — 自动保存每个文档的阅读位置，最近文档显示阅读进度
- ✏️ **编辑模式** — 快速修改文档内容并保存
- 💾 **本地文件支持** — 打开手机/平板上的 .md / .txt / .json 文件

## 🔧 WebDAV 配置

支持坚果云、NextCloud、群晖 NAS 等标准 WebDAV 服务：

1. 打开「网络存储」页面
2. 输入 WebDAV 地址（如 `https://dav.jianguoyun.com/dav/`）
3. 填写账号密码
4. 可先点击「测试连接」确认配置
5. 点击「连接」，浏览云端文档

WebDAV 体验增强：

- 自动补全地址协议、清理末尾斜杠
- 最近连接记录，常用地址一键回填
- 记住上次浏览目录，下次连接可自动恢复
- 下载提示改为底部轻量浮层，完成/失败会自动消失
- 普通提示驻留时间缩短为 0.5 秒，减少遮挡
- 默认优先使用 HTTPS 并严格验证证书；家庭 NAS 可手动允许自签名证书
